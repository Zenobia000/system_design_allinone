## 群組 1 · 網路與通訊

| 英文 | 中文 | 一句白話 |
|---|---|---|
| **HTTP / HTTPS** | 超文字傳輸協定 | 瀏覽器和 server 溝通的格式，HTTPS 加密 |
| **API** | 應用程式介面 | 服務對外開的「窗口」，前端打它拿資料 |
| **REST** | RESTful API | 用 GET/POST/PUT/DELETE 操作資源的 API 風格 |
| **CDN** | 內容分發網路 | 圖片影片放在邊緣節點，用戶就近抓快 |
| **Latency** | 延遲 | 一個請求要等多久才回來（毫秒） |

> 看到「網路」「請求」「回應」就想這 5 個詞

## 群組 2 · 資料庫基礎

| 英文 | 中文 | 一句白話 |
|---|---|---|
| **SQL / NoSQL** | 關聯式 / 非關聯式 | SQL 欄位固定；NoSQL 自由形態 |
| **ACID** | 事務 4 性質 | 原子 / 一致 / 隔離 / 永久（強事務） |
| **Index** | 索引 | 資料表的「目錄」，查快但寫慢 |
| **Transaction** | 事務 / 交易 | 一組操作要嘛全成功要嘛全失敗 |
| **OLTP / OLAP** | 交易型 / 分析型 | 處理訂單 vs 跑報表 |
| **Cache** | 快取 | 把熱資料放記憶體，比讀 DB 快百倍 |

> 看到「資料庫」「查詢」「儲存」就想這 6 個詞

## 群組 3 · 分散式核心

| 英文 | 中文 | 一句白話 |
|---|---|---|
| **CAP** | 一致性/可用性/分區 | 分散式系統三選二定理 |
| **Sharding** | 資料分片 | 資料拆到多台 DB（做了難回頭） |
| **Replication** | 複製 | 主庫寫、副本讀（讀放大 + HA） |
| **Consistent Hash** | 一致性哈希 | 加減機器搬動最少資料 |
| **Load Balancer** | 負載均衡器 | 把流量分到多後端機器 |

> 看到「擴展」「分散」「分佈」就想這 5 個詞

<!-- _class: compact -->

## 群組 4 · 可靠性與維運

| 英文 | 中文 | 一句白話 |
|---|---|---|
| **SLO / SLA** | 服務目標 / 合約 | 對內目標 vs 對外承諾 |
| **Idempotency** | 冪等性 | 同操作 1 次和 10 次結果一樣 |
| **Circuit Breaker** | 斷路器 | 下游死了就不要繼續打它 |
| **Rate Limit** | 限流 | 每秒最多 X 請求（防爆量） |
| **Observability** | 可觀測性 | Metrics + Logs + Traces 三本柱 |

> 看到「穩定」「故障」「監控」就想這 5 個詞

## 群組 5 · 模式與進階

| 英文 | 中文 | 一句白話 |
|---|---|---|
| **Queue** | 訊息佇列 | Kafka / SQS — 削峰、解耦、不掉資料 |
| **Pub/Sub** | 發布訂閱 | 發訊者只管發，訂閱者都收到 |
| **WebSocket** | 全雙工長連線 | 雙向即時推（聊天、直播） |
| **RAG** | 檢索增強生成 | 先查文件再給 LLM 寫答案 |

> 看到「非同步」「即時」「AI 應用」就想這 4 個詞
