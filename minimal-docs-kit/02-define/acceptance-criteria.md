## Exit Criteria(全部打勾才算完成)

- [ ] `prd.md` 的每條 FR 都有對應測試,且測試通過(見下表)
- [ ] 測試測的是「行為」,不是「實作照抄」——抽查至少 3 條:把實作故意改壞,測試要會紅
- [ ] 契約一致:實作與 `../03-design/api-spec.yaml` 對得上(用 contract test 或 schema validation)
- [ ] 主要錯誤路徑有測(不只 happy path)
- [ ] 沒有硬編碼秘密;外部輸入有驗證
- [ ] CI 綠燈,且 CI 跑的就是上面這些,不是另一套
