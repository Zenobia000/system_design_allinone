# 系統設計學習合集

> 四本講義，把你從「看不懂架構圖」帶到「能指揮 AI 設計系統」

---

## 這是什麼

四本獨立但互相銜接的講義，覆蓋系統設計學習的四個階段：

1. **從零開始** — 知道 IT 公司在做什麼
2. **打底架構觀念** — 看得懂、畫得出、能審查架構
3. **AI 時代速成** — 用 AI 加速設計，學會判斷力
4. **主題速查** — 工作上遇到問題，馬上查到對應技術

不是參考書、不是百科全書，**是教材**——每本都有起點、有路徑、有「學完帶得走的東西」。

## 四本講義

### 📗 軟體開發旅程 · `software_develop_journey/`

> 「為什麼一個 App 要 9 個角色？」

**給誰**：完全沒接觸過軟體開發的人、剛轉職、想了解自家公司分工的人

**核心比喻**：蓋一棟大樓 — PM 是企劃、UX 是室內設計、Architect 是結構技師、DBA 是水電管線、Dev 是工班、QA 是驗收員...

**學完你會**：
- 看懂招聘 JD 寫的「Backend Engineer」「SRE」「Architect」差在哪
- 知道一個 App 從想法到上線經過哪些角色的手
- 在會議裡聽得懂大家在吵什麼

[→ 進入](software_develop_journey/)

---

### 📘 架構師的藍圖 · `software_architect/`

> 「面對 Trade-off，怎麼做出可解釋的決策？」

**給誰**：寫過 1-3 年 code，發現「會寫不等於會設計」的工程師

**核心方法**：每章三段節奏 — **Why（為什麼存在）→ How（怎麼運作）→ Trade-off（代價是什麼）**

**學完你會**：
- 把模糊需求翻成可量化的技術指標（NFR / SLO / SLI）
- 30 秒在 SQL / NoSQL / Vector DB 之間做出選型
- 看一個架構圖能指出 SPOF（單點故障）和容量瓶頸
- 寫出能說服老闆與團隊的 ADR（架構決策紀錄）

12 章 · 從角色定位、需求量化、技術選型、品質屬性、設計模式、到分散式進階

[→ 進入](software_architect/)

### 🚀 AI 時代系統設計速成 · `ai_native_system_design/`  ⭐ 最新

> 「AI 把實作變便宜，判斷力變稀缺。這本只教稀缺的。」

**給誰**：想把 Claude Code、Cursor 等 AI 工具用得更深，但發現「會用 AI ≠ 設計得好」的人

**為什麼這本特別**：其他兩本不教 AI 工作流，這本整章專講「怎麼讓 AI 變成你的架構助理」

**學完你會**：
- 給 AI 結構化 context，不再亂下指令
- 用「三輪法」讓 AI 寫出可簽核的 ADR
- 跑 PoC → 驗證 → 迭代的閉環（不是只生 code）
- 知道 AI 容易在哪 7 種情境出錯，怎麼擋住

**特色**：
- 全書 30 張顧問風技術圖（中英雙語標籤）
- 每章末「三句帶走」海報式重點
- 圖文比例「圖為主、文為輔」
- 新手友善 — 50 詞詞彙表 + 每章開頭「本章新術語」預覽

[→ 進入](ai_native_system_design/)

### 📚 系統設計實戰 · `system_design/`

> 「這個技術解決什麼問題？什麼時候不該用？」

**給誰**：工作上遇到具體問題、想搞懂某個技術概念、面試前要刷主題

**內容**：7 章 × 48 主題的速查式講義 + 34 份 PDF 原始教材

**主題涵蓋**：
- **基礎**：網路、C/S、API、CAP 定理、索引、事務
- **資料**：分片、複製、快取、Sharding 拓樸
- **基建**：資料庫、Blob、Gateway、Container、Serverless
- **可靠性**：分散式鎖、過載控制、訊息投遞、可觀測性
- **進階**：訊息佇列、長任務、即時通訊、搜尋、Pipeline、RAG

**學完你會**：能單點深入查詢任何技術概念，看完就懂為何選它、代價在哪

## 學習設計理念

四本講義共通的三個堅持：

### 1️⃣ 不背名詞，學決策
每張投影片真正在問三件事：
> 這個技術解決什麼問題？代價是什麼？什麼時候不該用？

如果能回答這三題，你就是架構師。

### 2️⃣ 圖為主，文為輔
所有架構流程、決策樹、模式對比都用真實技術圖（不是 ASCII / markdown 拼出來的）。一張好圖勝過十段文字。

### 3️⃣ 心法 + 三句帶走
每章關鍵段落有「💡 心法」貼條，章末有「三句帶走」海報式總結。讓你**讀完馬上記得住**。
