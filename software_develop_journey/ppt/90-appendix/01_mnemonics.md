# 全局三句

<br>

<div class="highlight">

**1.** 軟體工程的本質是**管理複雜度**。

</div>

<div class="highlight">

**2.** 角色不是用職稱分，而是用負責消除哪一種**不確定性**來分。

</div>

<div class="highlight">

**3.** 開發 = 三層翻譯——**User Flow → System Flow → Architecture Flow**。

</div>

## MNEMONICS · 9 角色口訣（前半）

| 角色 | 口訣 1 | 口訣 2 |
|---|---|---|
| PM | 需求壓縮器，不是客戶傳聲筒 | 主導做什麼，不主導怎麼做 |
| UX | UX 是動線、UI 是樣品屋 | 可用性測試比品味重要 |
| SA | SA 補規則的縫隙 | 管系統怎麼跑，不管系統怎麼活 |
| Architect | 架構師掌控複雜度 | 向上翻商業、向下翻技術 |
| SD | SD 是架構與代碼的橋 | API 命名是 SD 的靈魂 |

## MNEMONICS · 9 角色口訣（後半）

| 角色 | 口訣 1 | 口訣 2 |
|---|---|---|
| DBA | 不只是建表，是守住資料生命線 | Schema 不是技術問題是業務問題 |
| Dev | Dev 不是工人是工班師傅 | AI 寫 code 之後，價值是判斷該寫什麼 |
| QA | 不是按按鈕的人，是設計驗證框架的人 | AI 時代 QA 從驗證已知變成定義未知 |
| DevOps | 不是水電工是物業管理 | 監控不是事後補救，是事前約定 SLO |
