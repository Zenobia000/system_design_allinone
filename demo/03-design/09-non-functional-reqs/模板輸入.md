## ⚠️ 本卡注意事項（進 Claude 前先讀）

- **每條 NFR 必須含「SLI + SLO target + measurement + test_method」四件套缺一不可**。只寫「要快」「要穩」沒有量測方法等於沒寫，會被退件。
- **不抄業界數字**。看到「99.9% 因為大家都這樣寫」立刻擋下 — 必須從 business impact 推導，本案是 MVP 個人工具 → 99.5% 才對得起 error budget。
- **latency / availability / scalability / reliability / security / privacy / compliance / a11y / cost / operability 九象限缺一不可**。不適用要寫「N/A + 原因」，不能空著。
- **「無 PII」≠ 跳過 privacy**。destination / dates / mood / note 是 session_sensitive 行為資料，GDPR 一樣管。學生若寫「無 PII 故 GDPR N/A」會被合規審查退件。
- **graceful degradation 是「good failure mode」不是 failure**。FX provider 掛掉時切 simulated 模式 + UI 提示 = 成功；別把 fallback 算進 error budget。

### PRD 中的模糊承諾（待改寫為可量測 SLI/SLO）

- 「**3 分鐘內**得到一份含建議換匯額的行程」（G1 / §7 領先指標）— **可量測**

- 「**免登入、即開即用**」（主要約束）— 可改寫為 page load p75 + a11y
- 「**重隱私**」（PRD §9 P0-9 Open Question）— 改寫為 data classification 控制

## 替換成自己專案的方法

如果你不是要做 SmartTrip FX：

1. 跑 [`/start/`](http://localhost:3000/start/) 問卷 → 下載你自己的 `project-brief.md`，並跑完 [`03-prd/`](../../02-define/03-prd/模板輸入.md) + [`06-c4-diagram/`](../06-c4-diagram/模板輸入.md) + [`07-api-spec/`](../07-api-spec/模板輸入.md) + [`08-data-model/`](../08-data-model/模板輸入.md) 拿到上游輸出
2. 步驟 1（複製站上「完整範本」tab）**完全不動**
3. 步驟 2 的 trigger 結構不動；**只替換 `⏫` 上方的「上游文件」貼位區**（把 PRD 模糊承諾 / Business impact / 既有基線 / 上游 PRD / 上游 C4+API / 上游 Data Model 6 個小節換成你自己的對應內容）
4. 貼到 Claude → 對比你拿到的結果與 [`實際結果.md`](./實際結果.md) 的「教學要點」與「常見錯誤」

> **為什麼步驟 1 不動？** 因為站上模板就是 single source of truth。版本升級（規則修訂、章節增刪）會自動同步到所有學生的下次產出，不需要去改舊的 demo 檔。
