# 幕 99：結業 Capstone — 架構白皮書整合

> 課程終章。五幕走完，一份白皮書從空白長到 v5。這一章把整條主線攤開，讓學員看見自己走過的每一步。

---

## 章節敘事

本章是架構師 101 的結業 Capstone，主角依然是 IoT 設備監控系統（10,000 台設備、6,000 msg/s 尖峰、P99 < 10s、99.9% 可用性、$20,000/hr 停機損失、6 人團隊、3 個月 MVP、雲費 < $5,000/月）。

五幕的第二螺旋——VCRE 決策——全部攤開做一次總複盤。學員在這裡看見：每個決策不是孤立的，它們共同組成一份能交付、能演進的架構白皮書。
