## UX · AI 協作模式

<div class="prompt">

**典型 prompt**：

```
這是我的 wireframe：[圖 / 文字描述]
扮演首次使用的 60 歲長輩，描述你的點擊路徑。
卡關在哪？哪些字看不懂？哪個按鈕你不敢按？
```

</div>

<br>

**AI 強**：線稿生成、icon、配色變體、A/B 文案、Tailwind 樣式。
**AI 弱**：真實使用者訪談、文化情境判斷、品牌一致性。
**陷阱**：AI 生的 UI 都「平均美」，缺辨識度—需要人加品牌個性。
