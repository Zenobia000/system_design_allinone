## SD · AI 協作模式

<div class="prompt">

**典型 prompt**：

```
領域：訂單系統
實體：Order、OrderItem、Payment、Shipping、Refund
互動：建單 → 付款 → 出貨 → 退款
請畫 PlantUML 序列圖 + REST API spec（OpenAPI 3.1）
標出：哪些步驟同步、哪些可改非同步、為什麼。
```

</div>

<br>

**AI 強**：OpenAPI / Protobuf spec、序列圖、ER 圖、模組骨架。
**AI 弱**：領域邊界（DDD bounded context）、API 演進策略。
**陷阱**：AI 設的 API 容易「太 RESTful」—實際業務常需要 RPC 風格。
