## GLOSSARY · 角色 / 流程

| 縮寫 | 全名 | 一句話 |
|---|---|---|
| PM | Product Manager | 產品經理（不是專案經理） |
| BA | Business Analyst | 業務分析師（偏需求分析） |
| PO | Product Owner | Scrum 的角色，管 Backlog |
| SA | System Analyst | 系統分析師（補規則的縫隙） |
| SD | System Design | 系統 / 軟體設計（模組與 API） |
| DBA | Database Administrator | 資料庫管理員 |
| SRE | Site Reliability Engineering | Google 命名的維運角色 |
| QA | Quality Assurance | 品質保證（驗收 + 測試） |
| SDET | Software Dev Engineer in Test | 寫測試自動化的工程師 |
| FE / BE | Frontend / Backend | 前端 / 後端工程師 |
| SDLC | Software Development Lifecycle | 軟體開發生命週期 |
| MVP | Minimum Viable Product | 最小可行產品 |

## GLOSSARY · 文件 / 產出

| 縮寫 | 全名 | 一句話 |
|---|---|---|
| PRD | Product Requirement Document | 產品需求文件 |
| ADR | Architecture Decision Record | 架構決策記錄 |
| NFR | Non-Functional Requirements | 非功能需求 |
| UML | Unified Modeling Language | 統一塑模語言（畫圖用） |
| ERD | Entity-Relationship Diagram | 資料庫關係圖 |
| C4 | Context / Container / Component / Code | 架構圖四層次方法 |
| API | Application Programming Interface | 應用程式介面 |
| REST | Representational State Transfer | 一種 API 設計風格 |
| DoD | Definition of Done | 完成的定義（QA / Dev 對齊用） |
| User Story | — | 「身為 X，我想要 Y，這樣 Z」格式 |

## GLOSSARY · 技術概念

| 縮寫 | 全名 | 一句話 |
|---|---|---|
| SLA | Service Level Agreement | 服務水準協議（對外承諾） |
| SLO | Service Level Objective | 服務水準目標（對內目標） |
| SLI | Service Level Indicator | 服務水準指標（實際量測） |
| RPO | Recovery Point Objective | 災難時最多容忍丟多少資料 |
| RTO | Recovery Time Objective | 災難時最多容忍多久還原 |
| CI/CD | Continuous Integration / Delivery | 持續整合 / 持續交付 |
| IaC | Infrastructure as Code | 基礎設施即代碼 |
| OLTP | Online Transaction Processing | 線上交易處理（電商型） |
| OLAP | Online Analytical Processing | 線上分析處理（報表型） |
| CDN | Content Delivery Network | 內容傳遞網路（直播 / 圖片用） |
| Saga | — | 跨服務交易補償模式 |
| Idempotency | — | 冪等性（重複呼叫結果一樣） |
