# 把 Ch.2 收成三句話

<br>

<div class="highlight">

**口訣 1**：PM 是**需求壓縮器**，不是客戶傳聲筒。

</div>

<div class="highlight">

**口訣 2**：客戶說的永遠**不是真需求**——挖到「可衡量的目標」才停。

</div>

<div class="highlight">

**口訣 3**：PM 主導**做什麼**，不主導**怎麼做**——越界會弄壞團隊信任。

</div>

# Ch.3：UX / UI · 室內設計師

<div class="note">

PM 寫了 PRD「會員忘記密碼」，現在問題變成：

- 流程要分幾頁？
- 點哪個按鈕？
- 失敗訊息怎麼寫？
- 在手機上長什麼樣？

**這些都是 UX / UI 的事**。

</div>

<br>

<span class="muted">**承先啟後**：PM 給的是 What，UX/UI 把它變成 How（使用者體驗的 how）。</span>
