# Pitch Deck 生圖 Prompts（image-first 高質感版）

> 上游：`STORYBOARD.md`（逐頁腳本）→ 本檔（生圖 prompt）→ gpt-image-2 → `pitch/generated/`
> 尺寸：1536×1024（產出後 center-crop 至 1536×864 = 16:9，prompt 內已留上下安全邊界）
> 版本：v0.1 · 2026-08-13

---

## 全域風格鎖（每個 prompt 前綴，杜絕頁間風格漂移）

```
STYLE：16:9 企業簡報投影片，米白紙感背景(#F5F1E8)，深棕墨色文字(#2A2520)，
赤陶橘為唯一強調色(#D97757)，深棕色塊(#2A2520)可作圖表底。
編輯級排版：優雅襯線體大標題、乾淨無襯線體內文，文字左對齊為主，大量留白。
扁平向量插圖與細線條圖，無漸層、無 3D、無光影特效、無 stock photo、無人物照片。
質感參考：高級財經雜誌內頁 × 頂級顧問公司簡報。畫面上下各留出約 8% 空白安全區。
所有中文與英文文字必須拼寫正確、筆畫清晰、完整可讀，禁止亂碼與錯字。
```

## 反通病守則（寫 prompt 時遵守）

1. 一頁只有一個視覺焦點——圖即論點，不放裝飾圖
2. 頁面文字量壓到最少（標題 + ≤5 短行），豐富度靠圖表資訊密度，不靠字多
3. 不用三欄卡片、齒輪、燈泡、握手、火箭等 AI 簡報陳腔意象
4. 版式刻意變化：statement 頁置中、資料頁左文右圖、圖表頁全幅——但配色字體永遠一致
5. 數字一定放大呈現，來源小字註記

## P1 · 封面

**內容**：主標「AI 時代的取捨與決策樹」、副標「何時 Vibe、何時 SDD、何時放手讓 AI 跑」、頁腳小字「SOFTWARE ENGINEERING IN THE AGENT ERA · 2026」。

**Prompt 主體**：
封面版式：左下角放置大號襯線體中文主標題「AI 時代的取捨與決策樹」分兩行，其下一行橘色無襯線副標「何時 Vibe、何時 SDD、何時放手讓 AI 跑」。右上大片留白處，畫一棵極簡細線條決策樹圖形：一個起點分岔成三條路徑，末端各一個小圓節點，其中一條為橘色。底部小字「SOFTWARE ENGINEERING IN THE AGENT ERA · 2026」。

**Prompt 主體**：

## P3 · 測試全綠，邏輯是錯的

**內容**：標題「更可怕的是：測試全綠，邏輯是錯的」。三行遞進：以前的錯一跑就炸／現在的錯架構合理測試全綠／但 domain logic 錯了三個月才發現。視覺：一排綠勾中藏一個紅叉。收尾句「錯誤沒有變少，它變安靜了。」

**Prompt 主體**：
左文右圖版式：左側標題「更可怕的是：測試全綠，邏輯是錯的」（襯線體，底下一條橘色短橫線），下方三行內文「以前的錯：一跑就炸」「現在的錯：架構合理、API 能跑、測試全綠」「domain logic 是錯的——三個月後才有人發現」，最後一行橘色。右側畫一個 4×4 的測試結果矩陣：十五個綠色打勾圓形整齊排列，其中一格是暗紅色叉，但視覺上不顯眼、幾乎混入其中。底部一行灰色小字「錯誤沒有變少，它變安靜了。」

**Prompt 主體**：
