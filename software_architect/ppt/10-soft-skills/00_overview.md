## MENTAL MODEL · 架構師的權力模型

```
   傳統 manager                架構師
   ────────────                ──────
   權力來源：職位               權力來源：專業 + 信任
   工具：命令                   工具：說服 + 範例
   失敗：員工離職               失敗：建議被無視

   架構師的「軟」實力 = 真正的硬功夫
   不練 → 技術再強都推不動
```

<span class="muted">**Linus 哲學**：強的不是寫得多酷的代碼，是讓**正確的代碼被寫出來**。</span>
