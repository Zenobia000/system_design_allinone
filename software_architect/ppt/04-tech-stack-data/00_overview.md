## MENTAL MODEL · 採購清單心態

```
   選技術 ≠ 比賽誰最酷
   選技術 = 評估「總擁有成本」(TCO)

   六個維度：
   ① 適用性     · 解決你的問題嗎？
   ② 成熟度     · 上線會炸嗎？
   ③ 社群       · 出 bug 找得到答案嗎？
   ④ 人才       · 招得到、留得住？
   ⑤ 授權成本   · 商用版多少錢？vendor lock-in？
   ⑥ 演進路徑   · 5 年後還在嗎？
```

<span class="muted">**Linus 哲學**：選技術像選結婚對象——不要因為「新」，要因為「對」。</span>
